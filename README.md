# dacnetwork.io

Official static website for **[dacnetwork.io](https://dacnetwork.io)**.

This repo is the site source/build. Hosting remains on dacnetwork.io (Hostinger). It is not GitHub Pages.

## Product truth (current)

- **DACx** Android beta **1.5.7** — wallet on **Solana Devnet**, not mainnet `$DAC`. Messages are not E2EE. Voice exists in the UI; not E2EE.
- **rutaX** rewards run on **Devnet**, not mainnet.
- **`$DAC`** is a **utility token**, not an investment. No active public sale.
- Association: **registration in progress** (OG 26/2000). Not yet in the official register.
